# 한솔 다골프 회원권 관리 대시보드

골프 회원권 매매 현황을 한눈에 파악할 수 있는 웹 대시보드입니다.

## 실행 방법

### 로컬 실행
`index.html` 파일을 브라우저에서 직접 열면 됩니다.

### GitHub Pages (온라인)
아래 링크에서 바로 접속할 수 있습니다.  
> 배포 후 GitHub 저장소 Settings → Pages에서 URL을 확인하세요.

## 기능
- 회원권 매물 현황 관리
- 매매 실적 통계 및 차트
- 담당자별 실적 관리
- 월별 히스토리 조회

## 배포 방법

1. 이 저장소를 GitHub에 Push
2. GitHub 저장소 → **Settings** → **Pages**
3. Source: **GitHub Actions** 선택
4. `main` 브랜치에 Push 하면 자동 배포됩니다
